# Draw & Duel 作画对决 (Godot 4.x Demo)

2D 横版 PVP 演示：先**画出你的装备**，AI 将画作"渲染"成装备贴图并根据笔画分析出属性，然后与 AI 对手进行平台格斗。

## 运行方式

### Windows 直接运行（推荐）

下载/解压 `builds/DrawAndDuel-Windows-x64.zip`，双击 `DrawAndDuel-Windows-x64.exe` 即可（单文件，资源已内嵌，无需安装）。首次运行如被 SmartScreen 拦截，点击"更多信息 → 仍要运行"。

### 从源码运行

1. 安装 [Godot 4.x](https://godotengine.org/download)（4.3+ 推荐，无需额外插件）。
2. 在 Godot 项目管理器中 **Import** 本文件夹（选择 `project.godot`），或命令行运行：

   ```bash
   godot --path draw-pvp-demo
   ```

## 玩法

### 阶段一：作画 (画装备)

用鼠标在三个画布上作画：**武器**、**护甲**、**饰品**。下方按钮切换画笔颜色，`清空` 重画，`开始战斗` 进入战斗。AI 对手的装备由程序自动"作画"生成，走同一套分析管线。

画作如何影响属性（启发式分析，无需外部 AI 接口）：

| 特征 | 效果 |
| --- | --- |
| 横向长条 (宽高比 ≥ 1.8) | 武器 = **长枪**：攻击距离远、伤害较低 |
| 笔画密集 (密度 ≥ 13%) | 武器 = **剑**：近战、伤害最高 |
| 笔画稀疏 | 武器 = **弓**：发射远程箭矢 |
| 笔画越密 | 攻击 / 护甲值越高 |
| 笔画越稀疏（护甲） | 轻甲：移动速度加成 |
| **红色** | 武器：火焰(+15% 攻击)；护甲：**荆棘** 反弹 15–30% 近战伤害 |
| **蓝色** | 武器：冰冻(命中减速)；护甲：**盾牌**（解锁 K 格挡）；饰品：+护甲 |
| **绿色** | 回复：每秒恢复生命；饰品另 +生命上限 |
| **深色** | 重甲：+护甲值 +防御 |
| 瘦高的画（饰品/护甲） | +闪避（移动速度） |

画完后画作会经过"AI 渲染"处理（调色板归一 + 泛光），作为武器/护甲贴图显示在角色身上。

### 阶段二：战斗

1280x720 横版竞技场（渐变夜空 + 远山剪影 + 地砖），玩家在左（蓝），AI 在右（红）。护甲条（灰）先于生命值（绿）吸收伤害。技能带粒子特效、刀光轨迹、技能名弹字、光环与屏幕震动。击败对手后显示结算画面，可点击 `再来一局` 重新作画。

AI 为简单状态机：接近 → 攻击 → 低血量时撤退，会尝试格挡与跳跃躲箭。

## 操作

| 按键 | 动作 |
| --- | --- |
| A / D | 左右移动 |
| K / W / 空格 | 跳跃 |
| S | 地面：下蹲（变矮减速，可躲箭）；空中：速降 |
| J | 普通攻击（剑=挥砍 / 长枪=突刺 / 弓=射箭） |
| W + J | 上派生技（W 按住或 0.15 秒内缓冲输入） |
| S + J | 下派生技（需在地面） |
| L | 格挡（需要蓝色护甲，减免正面 70% 伤害） |
| U / I / O | 技能 1 / 2 / 3（见下表） |

### 方向派生技（每种武器 3 套：J / W+J / S+J）

| 武器 | W + J | S + J |
| --- | --- | --- |
| 剑 | **升龙斩**：跃升挥击 1.3 倍伤害 + 刀光轨迹 | **地裂波**：沿地面推进的冲击波 |
| 长枪 | **挑空刺**：跃升突刺 | **横扫千军**：超宽低位横扫 |
| 弓 | **箭雨**：5 支箭从敌人头顶落下 | **陷阱地雷**：脚下布雷，敌人靠近引爆 1.4 倍伤害 |

派生技共享约 2.5 秒冷却。你的画作会成为武器本体：武器画布的图案会被裁剪、描边、加辉光后直接作为角色手中的武器贴图；护甲画作为身体色调 + 半透明护甲覆盖层；饰品画缩小后悬浮在肩侧。近战判定框还会随武器画的宽高比变化（横长=细长扫击，团块=高大判定）。

## 技能系统

三个技能槽由三幅画作分别决定，HUD 显示冷却倒计时，AI 也会择机放技能：

| 槽位 | 来源 | 判定 | 技能 |
| --- | --- | --- | --- |
| U | 武器画 | 红色武器 | **火焰斩**：加长挥击 +20% 伤害，附加 3 秒灼烧 (CD 6s) |
| U | 武器画 | 蓝色武器 | **冰锥**：冰冻弹，命中减速 (CD 5s) |
| U | 武器画 | 弓 | **强力射击**：1.8 倍伤害穿透箭 (CD 7s) |
| U | 武器画 | 剑 / 长枪 | **突进斩**：短距冲刺 + 挥击 (CD 6s) |
| I | 护甲画 | 绿色（回复） | **回复爆发**：立刻回复 20% 生命 (CD 10s) |
| I | 护甲画 | 红色（荆棘） | **荆棘爆发**：环形尖刺，伤害近身敌人 (CD 8s) |
| I | 护甲画 | 蓝盾 / 深色重甲 | **铁壁**：4 秒内受伤减 60% (CD 12s) |
| I | 护甲画 | 轻甲（稀疏） | **影步**：短暂无敌冲刺 (CD 7s) |
| O | 饰品画 | 按颜色映射 | 红→火焰斩 / 蓝→冰锥 / 绿→回复爆发 / 深→铁壁 / 其他→影步 |

## 已知限制（Demo 范围）

- 画作分析为本地启发式规则，非真实 AI 生成。
- 角色为几何图形拼装，无骨骼动画。
- 仅单场景 1v1，无音效。
