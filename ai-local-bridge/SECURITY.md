# 安全说明(使用前必读)

## 这个工具已经做了什么

- **最小暴露面**:只有 `config.json` 里 `root_dir` 指定的**一个文件夹**可被访问;
  `..`、绝对路径、盘符、符号链接逃逸均被服务端拒绝(见 `server.py` 的 `safe_resolve`)。
- **强制鉴权**:所有接口(包括 `/api/health`)都要求 `Authorization: Bearer <token>`,
  token 为 43 位随机字符串,使用常数时间比较,防暴力猜测与时序攻击。
- **默认只监听 127.0.0.1**:不开隧道时,局域网和外网都无法访问。
- **写入保护**:覆盖旧文件前自动备份到 `.ai-bridge-backup/`;备份目录禁止被接口写入;
  单次写入上限 20MB;可开 `read_only` 只读模式。
- **无遥测**:代码零第三方依赖,除了你自己启动的 cloudflared 隧道,不会发起任何对外连接。

## 仍然存在的风险(请知悉)

1. **网址 + 令牌 = 完整访问权**。任何拿到 trycloudflare 网址和 token 的人,
   都能读写 `root_dir` 里的全部文件。不要把这两样东西发到公开场合。
2. **cloudflared 是第三方程序**(Cloudflare 官方开源)。它只负责转发流量,
   但流量会经过 Cloudflare 的服务器(有 HTTPS 加密)。介意的话可换成自己的转发方案。
3. **本工具不做操作审计与限速**。AI 可以高频读写 `root_dir` 内文件;
   备份能挽回覆盖,但不能挡住写入大量垃圾文件。
4. **quick tunnel 网址无法预先控制**,且在中国大陆网络下可能不稳定、随时断线。

## 安全使用建议

- **root_dir 越小越好**:只指向具体项目文件夹(如 `D:/剧本`),
  **绝对不要**填 `C:/`、`C:/Users/你` 这类大范围目录。
- **用完就关**:关闭 `start_tunnel.bat` 窗口即断开外网入口;两个窗口都关掉则服务完全停止。
- **定期换令牌**:把 `config.json` 的 `token` 清空后重启,即生成新令牌、旧令牌作废。
  怀疑令牌泄露时立即执行此操作。
- **只需要读时开只读**:`read_only: true` 可从根源上杜绝文件被改。
- **重要文件先自己备份**:`.ai-bridge-backup/` 是最后一道保险,不是版本管理。
